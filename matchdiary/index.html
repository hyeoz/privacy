직관일기 개인정보처리방침

시행일 2026년 9월 3일

요약

직관일기는 회원가입이나 로그인을 요구하지 않으며, 새로 작성한 프로필·직관 기록·사진·티켓을 기기 안에 저장합니다. 운영자는 새 기록을 보관하는 상시 백엔드 서버를 운영하지 않습니다. 경기 일정 갱신과 Google AdMob 광고에만 네트워크를 사용합니다. 기존 버전 데이터는 요청한 사용자에게만 본인 확인 후 개별 복구 파일로 제공합니다.

1. 처리하는 정보

항목처리 방식목적
닉네임과 응원 팀 기기 내 저장 앱 화면 개인화
경기 날짜·상대 팀·경기장·점수·좌석·메모 기기 내 저장 및 계산 직관 기록, 캘린더, 통계와 지도 제공
사용자가 선택한 사진과 티켓 이미지 앱 전용 저장 공간에 복사 직관 기록 표시, 공유 및 백업
알림 시간 기기 내 저장 및 로컬 예약 경기 관람 알림 제공

IP 주소, 대략적 위치, 기기·앱 범위 식별자, 광고 노출·상호작용, 성능·진단 정보 Google Mobile Ads SDK가 처리할 수 있음 광고 제공, 빈도 관리, 성과 측정, 분석과 부정 사용 방지

앱은 이메일 주소, 전화번호와 같은 계정 정보를 요구하지 않습니다. 메모에는 실명, 연락처 등 개인을 직접 식별할 수 있는 정보를 입력하지 마십시오.

2. 기기 내 저장과 백업

새 프로필과 직관 기록은 로컬 데이터베이스에, 선택한 사진과 티켓은 앱 전용 파일 영역에 저장됩니다. 사진을 기록에 추가하면 원본과 별도의 사본을 만들기 때문에 사진 보관함에서 원본을 삭제해도 기록의 사본은 유지됩니다.

사용자가 설정 → 백업 생성을 선택하면 기록과 이미지가 포함된 .matchdiary 파일을 사용자가 선택한 앱 밖의 위치로 내보냅니다. 백업 파일은 민감한 개인 기록과 이미지를 포함할 수 있으므로 사용자가 직접 안전하게 보관해야 합니다. 운영자는 해당 백업 파일에 접근하지 않습니다.

3. 경기 일정

앱은 공개된 정적 파일에서 KBO 경기 일정과 결과를 내려받습니다. 이 요청에는 사용자의 직관 기록, 사진, 닉네임이나 정밀 위치가 포함되지 않습니다. 내려받은 일정은 기기에 캐시되며 네트워크가 없으면 마지막으로 저장한 일정 또는 앱에 포함된 기본 일정을 사용합니다.

4. 기존 사용자 개별 복구

기존 버전에서 서버에 저장했던 기록이 필요한 사용자는 지원 이메일로 개별 복구를 요청할 수 있습니다. 앱은 기존 데이터를 자동으로 조회하거나 가져오지 않습니다. 운영자는 요청자에게 본인 확인에 필요한 최소 정보를 별도로 안내하고, 확인된 본인 데이터만 앱에서 불러올 수 있는 .matchdiary 파일로 제공합니다.

  • 본인 확인 전에는 데이터의 존재 여부나 내용을 제공하지 않습니다.
  • 닉네임, 응원 팀, 기록 날짜처럼 공개되었거나 추측 가능한 정보만으로 본인 확인을 완료하지 않습니다.
  • 복구 파일은 암호화하거나 짧게 만료되는 비공개 전달 수단으로 요청자에게만 제공합니다.
  • 임시 추출물과 전달용 파일은 제공 완료 또는 유효기간 만료 후 삭제합니다.
  • 복구한 새 로컬 기록은 이후 운영자 서버로 동기화하지 않습니다.

보호된 기존 원본 데이터는 복구 지원과 이용자 요청 대응에 필요한 기간 동안 접근이 제한된 상태로 보관한 뒤 복구 운영 종료 절차에 따라 삭제합니다. 복구 전 원본 데이터의 조기 삭제를 원하는 경우 제11항의 이메일로 요청할 수 있습니다.

5. 광고와 제3자 처리

앱은 Google AdMob을 통해 배너와 전면 광고를 표시합니다. 광고 요청은 맞춤형이 아닌 광고로 설정합니다. Google Mobile Ads SDK는 광고 제공 과정에서 IP 주소로 추정한 대략적 위치, 기기 또는 앱 범위 식별자, 광고 노출·상호작용 정보, 앱 성능 정보와 진단 정보를 처리할 수 있습니다.

동의가 필요한 지역에서는 광고를 요청하기 전에 Google 사용자 메시지 플랫폼(UMP)을 통해 동의 선택지를 제공합니다. 해당 지역에서는 앱의 설정 → 광고 개인정보 옵션에서 선택지를 다시 열 수 있습니다. 광고에 동의하지 않거나 광고를 불러오지 못해도 기록, 일정, 백업과 알림 기능은 계속 사용할 수 있습니다.

Google의 데이터 처리에 관한 자세한 내용은 Google 개인정보처리방침과 Google 광고 데이터 안내를 참고하십시오.

앱은 iOS의 앱 추적 투명성(ATT) 권한을 요청하지 않습니다. 운영자는 광고 외에 사용자의 정보를 판매하거나 데이터 브로커에게 제공하지 않습니다.

6. 사진과 알림 권한

  • 사진 권한: 사용자가 직접 선택한 사진이나 티켓을 기록에 추가하기 위해 사용합니다. 거부해도 이미지 없이 기록할 수 있습니다.
  • 알림 권한: 사용자가 지정한 경기 알림을 기기에서 울리기 위해 사용합니다. 푸시 토큰을 만들거나 서버로 전송하지 않습니다.

앱은 정밀 위치, 연락처, 마이크 권한을 요청하지 않습니다.

7. 보유 기간과 삭제

로컬 기록은 사용자가 개별 기록을 삭제하거나 설정 → 모든 데이터 삭제를 실행하거나 앱을 삭제할 때까지 기기에 남아 있습니다. 모든 데이터 삭제를 실행하면 프로필, 기록, 사진·티켓 사본, 알림 설정과 예약된 로컬 알림이 제거됩니다.

앱 밖으로 내보낸 백업 파일과 공유 이미지는 앱이 직접 삭제할 수 없습니다. 사용자가 저장한 파일 앱, 클라우드 저장소 또는 공유 대상에서 직접 삭제해야 합니다. Google이 처리하는 광고 관련 정보의 보유와 삭제는 Google 정책 및 사용자의 동의 설정에 따릅니다.

8. 이용자의 선택과 권리

  • 열람·이동: 앱 화면에서 기록을 확인하고 .matchdiary 백업으로 내보낼 수 있습니다.
  • 수정·삭제: 개별 기록을 수정·삭제하거나 설정에서 모든 로컬 데이터를 삭제할 수 있습니다.
  • 광고 개인정보 선택: 해당 지역에서는 설정에서 Google UMP 선택지를 다시 확인할 수 있습니다.
  • 기존 원본 데이터 요청: 기존 버전 서버 데이터의 확인·제공·삭제가 필요한 경우 아래 이메일로 문의할 수 있습니다. 본인 확인에 필요한 최소 정보만 별도로 안내합니다.

9. 안전성

일정 통신에는 HTTPS를 사용합니다. 기존 사용자 복구 파일은 본인 확인, 접근 제한, 암호화 또는 만료되는 비공개 전달 수단과 무결성 검증을 적용합니다. 운영자는 복구 목적 외에 사용자의 새 로컬 기록을 수집하거나 조회하지 않습니다.

10. 어린이 및 방침 변경

앱은 어린이를 주된 사용자로 의도하지 않으며 어린이의 개인정보를 알면서 수집하지 않습니다. 이 방침이 변경되면 변경 내용과 시행일을 이 페이지에 게시하고, 중요한 변경은 앱 업데이트 안내로 함께 알립니다.

11. 문의

개인정보 처리, 기존 데이터의 제공·삭제 또는 앱 사용에 관한 문의는 아래로 연락해 주십시오. 자세한 사용 안내는 지원 및 문의 페이지에서도 확인할 수 있습니다.
