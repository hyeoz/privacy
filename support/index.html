자주 묻는 질문

직관일기

회원가입이나 운영자 서버가 필요한가요?
아니요. 새 기록과 사진·티켓은 앱 전용 저장 공간에 보관되며 회원가입이나 로그인 없이 사용할 수 있습니다. 경기 일정 갱신, 광고 표시, 기존 버전 기록의 한시적 복구에만 네트워크를 사용합니다.

사진 앱에서 원본을 지우면 직관일기 사진도 사라지나요?
아니요. 기록에 추가한 사진과 티켓은 앱 전용 저장 공간으로 복사됩니다. 다만 앱을 삭제하거나 설정 → 모든 데이터 삭제를 실행하면 앱 전용 사본도 삭제되므로, 기기 변경 전에는 설정 → 백업 생성으로 .matchdiary 파일을 안전한 위치에 보관해 주십시오.

예전 버전에서 작성한 기록은 어떻게 복구하나요?
복구 지원 기간에는 예전 앱을 사용하던 원래 기기에서 앱을 업데이트하면 기기와 정식 앱을 확인한 뒤 본인 기록만 자동으로 가져옵니다. 설정의 기존 기록 자동 복구에서도 다시 확인할 수 있습니다. 다른 기기에서는 자동 복구할 수 없으며, 지원이 필요하면 아래 이메일로 문의해 주십시오.

광고 개인정보 설정을 바꾸고 싶습니다.
동의 선택지가 필요한 지역에서는 설정 → 광고 개인정보 옵션에서 다시 확인하거나 변경할 수 있습니다. 이 항목은 Google이 설정 변경을 요구하는 지역에서만 표시됩니다.

비타망고

추천을 받으려면 회원가입이나 인터넷 연결이 필요한가요?
아니요. 설문과 맞춤 추천은 앱에 포함된 데이터와 규칙으로 기기 안에서 처리되며, 회원가입·로그인이나 운영자 서버가 필요하지 않습니다. 광고를 불러올 때만 네트워크를 사용합니다.

추천은 의료 진단이나 처방인가요?
아니요. 비타망고의 추천은 설문 답변을 바탕으로 제공하는 일반적인 웰니스 정보입니다. 질환이 있거나 임신·수유 중이거나 약을 복용 중이라면 영양제를 시작하기 전에 의료 전문가와 상담해 주십시오.

복용 알림이 울리지 않습니다.
앱의 마이 → 복용 알림이 켜져 있는지, 해당 영양제의 알림과 시간이 설정되어 있는지 확인해 주십시오. 계속 울리지 않으면 기기의 설정에서 비타망고 알림 권한이 허용되어 있는지도 확인해 주십시오.

기기를 바꾸거나 앱을 다시 설치하면 기록이 복원되나요?
아니요. 계정과 서버 동기화가 없어 모든 기록은 현재 기기 안에만 저장됩니다. 앱을 삭제하면 기록도 함께 제거되며 복구할 수 없습니다.

광고 개인정보 설정을 바꾸고 싶습니다.
동의 선택지가 필요한 지역에서는 마이 → 광고 개인정보 설정에서 다시 확인하거나 변경할 수 있습니다. 이 항목은 Google이 설정 변경을 요구하는 지역에서만 표시됩니다.

찍을지도

사진을 선택했는데 지도에 지역이 채워지지 않습니다.
지도는 사진에 촬영 위치(EXIF GPS)가 들어 있을 때만 채워집니다. 촬영 당시 위치 서비스가 꺼져 있었거나, 메신저·SNS를 거쳐 받은 사진은 위치 정보가 제거된 경우가 많습니다. 기기 카메라로 위치를 켜고 찍은 사진으로 확인해 주십시오.

일부 사진만 허용했는데 계속 써도 되나요?
네. 허용한 사진 범위 안에서 정상 동작합니다. 나중에 기기의 설정에서 접근 범위를 넓힐 수 있습니다.

분석 데이터를 지우면 원본 사진도 지워지나요?
아니요. 설정 → 모든 분석 데이터 삭제는 앱이 만든 지도 데이터만 지웁니다. 사진 보관함의 원본은 그대로 남습니다.

인터넷이 없어도 되나요?
사진 분석과 지도 표시는 기기 안에서 이루어지므로 인터넷 없이도 동작합니다. 광고 표시에만 네트워크가 필요합니다.

광고 표시 방식을 바꾸고 싶습니다.
동의 선택지가 제공된 지역에서는 설정 → 광고 개인정보 선택에서 언제든지 다시 선택할 수 있습니다.

웨피캠

등록한 프레임이 사진을 완전히 가립니다.
프레임은 사진 위를 덮는 방식이라 배경이 투명한 PNG 파일을 사용해야 합니다. 배경이 흰색인 이미지는 사진 전체를 가립니다.

등록한 프레임·스티커를 지우고 싶습니다.
선택 화면에서 항목 좌상단의 삭제 버튼을 누르면 이미지와 이름이 함께 제거됩니다.

저장한 결과물이 사진 앱에 없습니다.
사진 저장 권한이 거부되어 있을 수 있습니다. 기기의 설정에서 해당 앱의 사진 권한을 확인해 주십시오.

데이터 삭제 요청

모든 앱은 데이터를 기기 안에만 저장하며 운영자 서버에 사용자 데이터를 보관하지 않습니다. 따라서 데이터 삭제는 사용자가 직접 완료할 수 있습니다.

  • 직관일기: 설정 → 모든 데이터 삭제
  • 비타망고: 마이 → 모든 데이터 삭제
  • 찍을지도: 설정 → 모든 분석 데이터 삭제
  • 웨피캠: 등록 항목의 삭제 버튼, 또는 앱 삭제
  • 공통: 앱을 삭제하면 앱이 만든 데이터가 함께 제거됩니다

그 밖에 확인이 필요한 사항은 위 이메일로 문의해 주십시오.
