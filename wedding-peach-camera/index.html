웨피캠 개인정보처리방침

요약

웨피캠은 사진을 꾸미는 모든 작업을 기기 안에서 처리합니다. 촬영한 사진, 불러온 사진, 등록한 프레임·스티커, 닉네임은 기기에만 저장되며 운영자 서버로 전송되지 않습니다. 회원가입과 로그인이 없고, 광고나 분석 도구를 사용하지 않습니다.

1. 처리하는 정보

항목처리 방식목적
카메라로 촬영한 사진 기기 내 처리, 사용자가 저장을 선택한 경우에만 사진 보관함에 저장 사진 꾸미기 및 결과물 저장
사진 보관함에서 선택한 사진 기기 내 처리, 앱이 별도로 보관하지 않음 사진 꾸미기
사용자가 등록한 프레임·스티커 이미지 앱 전용 폴더에 기기 내 저장 등록한 항목을 다시 사용
닉네임, 선택한 이모지 아바타, 즐겨찾기 목록 기기 내 저장(AsyncStorage) 프로필 표시, 테마 색상 적용, 자주 쓰는 항목 바로가기
텍스트 카드에 직접 입력한 내용 기기 내 처리, 결과 이미지에만 반영 다이어리 텍스트 카드 표시

닉네임은 사용자가 자유롭게 정하는 표시용 이름이며, 실명이나 연락처를 요구하지 않습니다.

2. 저장 위치와 전송

웨피캠은 운영자 서버를 운영하지 않습니다. 위의 모든 정보는 기기 내부에만 저장되며 외부로 전송되지 않습니다. 앱은 광고 네트워크, 사용자 분석 도구, 크래시 수집 도구를 포함하지 않습니다.

3. 공유 기능

완성한 이미지를 공유하면 기기의 시스템 공유 시트가 열리고, 사용자가 직접 선택한 앱이나 서비스로 이미지가 전달됩니다. 이때부터 해당 이미지의 처리는 사용자가 선택한 앱이나 서비스의 개인정보처리방침을 따릅니다. 웨피캠은 어떤 대상으로 공유했는지를 기록하지 않습니다.

4. 보유 기간과 삭제

  • 등록한 프레임·스티커는 목록의 삭제 버튼으로 이미지와 함께 제거할 수 있습니다.
  • 프로필과 즐겨찾기는 앱을 삭제하면 함께 제거됩니다.
  • 사진 보관함에 저장한 결과물은 사용자의 사진 앱에 남으며, 앱을 삭제해도 지워지지 않습니다. 필요하면 사진 앱에서 직접 삭제해 주십시오.

5. 권한

  • 카메라: 사진을 촬영하기 위해 필요합니다. 거부하면 촬영 기능만 사용할 수 없고, 사진 보관함에서 불러오는 방식은 계속 사용할 수 있습니다.
  • 사진 접근: 꾸밀 사진과 등록할 프레임·스티커 이미지를 불러오기 위해 필요합니다.
  • 사진 저장: 완성한 결과물을 사진 보관함에 저장하기 위해 필요합니다.

권한은 기기의 설정에서 언제든지 변경할 수 있습니다.

6. 어린이

앱은 일반 사용자를 대상으로 하며 어린이를 주된 사용자로 의도하지 않습니다. 어린이의 개인정보를 알면서 수집하지 않습니다.
