찍을지도 개인정보처리방침

시행일 2026년 8월 16일

요약

찍을지도는 사용자가 직접 고른 사진의 촬영 위치(EXIF GPS)를 기기 안에서만 분석해 방문 지도를 만듭니다. 사진 원본과 정밀한 위도·경도는 운영자 서버로 전송되지 않으며, 회원가입이나 로그인도 필요하지 않습니다. 앱은 기기의 실시간 위치 권한을 요청하지 않습니다.

1. 처리하는 정보

찍을지도(이하 "앱")가 처리하는 정보는 다음과 같습니다.

항목처리 방식목적
사진의 EXIF 촬영 위치(위도·경도) 기기 내 분석 후 행정구역 코드로 변환 방문 지도 생성
사진 촬영 일시 기기 내 저장 지역별 사진 정렬 및 표시
사진 보관함 자산 식별자 또는 파일 경로 기기 내 저장 원본을 복사하지 않고 사진을 다시 불러오기
행정구역 코드 및 지역별 사진 수 기기 내 저장 지도 색상과 통계 표시
광고 식별자, 기기·네트워크 정보, 광고 상호작용 Google AdMob이 처리 광고 제공 및 성과 측정

앱은 위 정보를 사용자가 사진 가져오기 기능에서 직접 사진을 선택했을 때에만 읽습니다. 사용자가 선택하지 않은 사진은 읽지 않습니다.

2. 이용 목적

  • 선택한 사진의 촬영 위치를 행정구역으로 변환해 방문 지도를 표시
  • 지역별 사진 목록과 대표 이미지, 사진 수 표시
  • 광고 제공, 노출 빈도 제한, 부정 사용 방지 및 광고 성과 측정

3. 저장 위치와 전송

사진 원본, 정밀한 GPS 좌표, 방문 지도 분석 결과는 기기 내부 저장 공간과 앱 전용 데이터베이스에만 저장되며 운영자 서버로 업로드되지 않습니다. 운영자는 사용자의 사진이나 위치를 조회할 수 있는 서버를 운영하지 않습니다.

사진의 좌표를 행정구역으로 판정하는 데 쓰이는 경계 데이터는 앱에 미리 포함되어 있어, 이 과정에서 외부 서버와 통신하지 않습니다. 따라서 인터넷 연결 없이도 사진 분석과 지도 표시가 동작합니다.

대부분의 사진은 사진 보관함의 자산 식별자만 저장해 참조합니다. 자산 식별자를 얻을 수 없는 사진에 한해, 앱이 표시를 위해 해당 이미지를 기기 내 앱 전용 폴더에 복사해 보관할 수 있습니다. 이 복사본 역시 기기를 벗어나지 않습니다.

4. 광고와 제3자 처리

앱은 Google AdMob을 통해 배너 광고를 표시합니다. 광고 제공 과정에서 Google 및 그 파트너가 광고 식별자, 기기 정보, 대략적인 위치, 네트워크 정보, 광고 상호작용 기록 등을 처리할 수 있습니다. 실제 처리 항목은 배포 시점의 Google Mobile Ads SDK 공개 내용과 사용자의 동의 설정에 따릅니다.

동의가 필요한 지역에서는 앱 최초 실행 시 Google의 사용자 메시지 플랫폼(UMP)을 통해 동의 선택지를 제공합니다. 동의를 거부해도 앱의 사진 분석과 지도 기능은 모두 사용할 수 있습니다.

Google의 데이터 처리에 관한 자세한 내용은 Google 개인정보처리방침과 Google 광고 데이터 안내를 참고하십시오.

광고 외에 사용자의 정보를 제3자에게 판매하거나 제공하지 않습니다.

5. 보유 기간과 삭제

방문 지도 데이터는 사용자가 직접 삭제하거나 앱을 삭제할 때까지 기기에 남아 있습니다. 앱 내 설정 → 모든 분석 데이터 삭제를 실행하면 앱이 저장한 분석 결과와 참조 정보가 모두 제거됩니다.

이 삭제 기능은 사진 보관함의 원본 사진을 삭제하지 않습니다. 앱을 삭제하면 앱이 만든 데이터베이스와 앱 전용 폴더의 복사본도 함께 제거됩니다.

광고 관련 정보의 보유 기간은 Google의 정책에 따릅니다.

6. 권한과 선택권

  • 사진 접근 권한: 사진을 선택하고 촬영 위치를 읽기 위해 필요합니다. 권한을 거부하거나 일부 사진만 허용해도 앱은 정상 실행되며, 허용한 범위 안에서만 동작합니다.
  • 광고 개인정보 선택: 동의 선택지가 제공된 지역에서는 설정 → 광고 개인정보 선택에서 언제든지 다시 선택할 수 있습니다.
  • 데이터 삭제: 설정 → 모든 분석 데이터 삭제에서 언제든지 실행할 수 있습니다.

앱은 기기의 실시간 위치 권한(GPS)을 요청하지 않으며, 사용자를 식별하는 계정 정보를 수집하지 않습니다.

7. 어린이

앱은 일반 사용자를 대상으로 하며 어린이를 주된 사용자로 의도하지 않습니다. 어린이의 개인정보를 알면서 수집하지 않습니다.

8. 이용자의 권리

앱이 처리하는 정보는 사용자의 기기 안에만 존재하므로, 사용자는 앱 내 삭제 기능과 기기의 권한 설정을 통해 열람·삭제·처리 중단을 직접 수행할 수 있습니다. 운영자는 사용자의 데이터를 별도로 보관하지 않아 대신 열람하거나 삭제해 드릴 수 있는 정보가 없습니다.

9. 방침 변경

이 방침이 변경되면 변경 내용과 시행일을 이 페이지에 게시합니다. 중요한 변경이 있을 경우 앱 업데이트 안내를 통해 함께 알립니다.
